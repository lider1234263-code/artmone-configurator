## 2. Технічна конфігурація

- Статичний односторінковий сайт без framework, package manager, build-команди, бази даних і серверного backend.
- Основний код: `index.html` — HTML, CSS та JavaScript в одному файлі.
- Додаткові файли: `_headers`, `manifest.json`, `assets/warehouse/`, `assets/mockups/`, `scripts/`, `.github/workflows/`.
- Мова UI: українська.
- Завантажені вебшрифти: DM Sans і Libre Caslon Display; частина базових стилів досі має fallback `Inter/-apple-system/Segoe UI/Arial`.
- Деплой: push у GitHub `main` публікується на Vercel через Git integration. Не використовувати ручне ZIP-завантаження для звичайних змін.
- Кеш: `index.html` — `no-cache, no-store, must-revalidate`; `assets/*` — один рік, `immutable`.
- Каталог: 47 кольорів стрічки у 7 групах.
- Друк: 34 кольори.
- Складські фото: 49 WebP-файлів у `assets/warehouse/` (включно з кодовими варіантами/аліасами).
- Галерея: 11 карток на колір, thumbnail → головне фото, `+` → lightbox.
- Очікувані назви файлів галереї:
  - `recolor_01.webp` … `recolor_07.webp`
  - `studio_01.webp` … `studio_03.webp`
  - `studio_white_bg_01.webp`
- Шлях визначається з AM-коду: `AM 850` → `assets/mockups/am-850/`.
- Фінальний стандарт нового фото: WebP, 1600×1600 px; тестові AM1/AM850 орієнтовно 100–180 KB на файл.
- Якщо очікуваного файла немає, UI показує placeholder.

## 4. Бізнес-правила калькулятора

### Метраж і прайсова сходинка

- Мінімум однієї позиції: 100 м.
- Максимум однієї позиції в UI: 10 000 м.
- Метраж лише кратний 100 м; ручне значення округлюється до найближчих 100 м і обмежується діапазоном 100–10 000 м.
- Кнопки: 100, 200, 300, 400, 500, 1 000, 2 000, 3 000, 4 000, 5 000, 10 000 м.
- `ХІТ`: 300 і 500 м.
- Між сходинками застосовується ціна найближчої нижчої сходинки. Наприклад, 600–900 м рахуються за ціною 500 м; 1 100–1 900 м — за ціною 1 000 м.

### Колір друку

- Чорний друк: входить у ціну, доплата 0 грн/м.
- Решта 33 кольори: +4 грн/м.
- Група `Однотонні Стандарт` доступна лише для світлих стрічок із whitelist:
  `AM 11`, `AM 6`, `AM Silver`, `AM 10`, `AM 810`, `AM 305`, `AM 714`, `AM 513`, `AM 117`.
- `Однотонні Стандарт+` та інші групи не мають цього обмеження.

### Термін виготовлення

- Стандарт: 4–6 робочих днів; розрахункова дата відправки додає 6 робочих днів.
- Терміново: 1–2 робочі дні; розрахункова дата додає 2 робочі дні; +20% до всієї вартості позиції після додавання доплати за колір друку.
- Субота та неділя не враховуються. Окремого календаря свят у коді немає.
- Якщо хоча б одна позиція термінова, загальна підказка відправки показує терміновий режим.

### Кілька стрічок і збереження

- До 20 позицій в одному замовленні.
- Для кожної позиції окремо зберігаються колір, ширина, друк, метраж і терміновість.
- Є додавання, дублювання, редагування та видалення з confirmation modal.
- Autosave: browser `localStorage`, ключ `artmone_satin_config_v2`.
- Share link: параметр `cfg` у URL; передаються налаштування максимум 20 позицій.
- Логотипи не входять до autosave/share payload і після нового сеансу не відновлюються.

### Логотип

- Приймаються PNG, JPG/JPEG, SVG та PDF.
- Для PNG/JPG/SVG однотонний фон намагається прибиратися в браузері.
- Можна застосувати спільний логотип або окремий логотип до позиції.
- Файл обробляється локально в браузері; серверного завантаження немає.

## 6. Невирішені питання і технічний борг

### P0 — блокує нормальний продаж або масове наповнення

1. Кнопки `ЗАМОВИТИ`, `ЗВ’ЯЗАТИСЬ З МЕНЕДЖЕРОМ` і мобільний CTA замовлення не мають фінальної передачі заявки менеджеру.
2. `Надіслати прорахунок собі` лише записує контакт у `localStorage`; нічого не надсилає.
3. `Потрібна допомога з вибором?` лише показує toast про майбутнє підключення.
4. AM567 є default-кольором, але його 7 старих файлів мають назви `01-bouquet.webp` … `07-many-rolls.webp`, несумісні з новими `recolor_*`/`studio_*`; на новій галереї видно placeholders.
5. Масовий pipeline `Pletor → Google Drive → GitHub → Vercel` не реалізований.

### P1 — потрібно прибрати перед масовим імпортом

1. `assets/import/` містить лише `chunk_00.txt`–`chunk_03.txt` із 13 очікуваних частин та пошкоджений `bundle.zip`.
2. `assets/mockups/am-1/am1_gallery_webp.zip` пошкоджений і більше не потрібний.
3. `.github/workflows/import-gallery-zips.yml` чекає 13 частин і завершується успішно без імпорту, якщо їх менше.
4. `.github/workflows/unpack-am1-gallery.yml` спрямований на пошкоджений старий ZIP.
5. `README_TECH_ONLY_UA.txt` описує стан до появи нових галерей.
6. `manifest.json` містить застарілу заяву про 11 186 prebuilt-зображень; таких файлів у репозиторії немає.

### P2 — якість і підтримка

1. Немає автоматичних browser/E2E тестів калькулятора, мобільного UI та галереї.
2. Немає автоматичного валідатора: рівно 11 файлів, правильні імена, WebP, 1600×1600, допустимий розмір.
3. Код і стилі зосереджені в одному великому `index.html`; це підвищує ризик конфліктів.
4. Через `immutable` кеш для assets заміна файла під тим самим ім’ям може залишити старе фото у браузері. При заміні потрібне нове ім’я або контрольована зміна cache policy/versioning.
5. Vercel connector у цій сесії не повернув teams/projects, тому project ID, build duration і dashboard-статус не зафіксовані. Публічний live та відповідність artifact перевірені напряму.
